# API Authentication

The AcmePay API uses authentication to verify the identity of the application making an API request.

This guide explains the authentication methods commonly used with APIs and shows how authentication works with the AcmePay API.

> **Note:** AcmePay is a fictional API created for this technical writing portfolio.

---

## Authentication Methods

Applications can use several approaches to authenticate API requests.

Common methods include:

- API keys
- Bearer tokens
- OAuth 2.0

The method used depends on the API and the type of application connecting to it.

---
