# Getting Started with the AcmePay API

This guide walks you through the basic steps required to make your first request to the AcmePay API.

By the end of this guide, you will understand how to:

- Authenticate an API request
- Send a request to the AcmePay API
- Read an API response
- Identify common errors

---

## Before You Begin

You will need:

- An AcmePay account
- An API key
- An API client such as Postman or cURL
- Basic familiarity with HTTP requests

> **Note:** AcmePay is a fictional API created for this technical writing portfolio.

---

## Step 1: Get Your API Key

API requests require authentication.

After creating an AcmePay account, you can find your API key in the developer dashboard.

Your API key should be treated as a secret.

**Never publish your API key in documentation, source code, screenshots, or public repositories.**
